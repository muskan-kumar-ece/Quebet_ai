# Cognitive Engineering Foundation (Phase 2 Wave 1 & 1.1)

## 1. Overview & Core Philosophy
The QUEBET AI Cognitive Engineering Layer provides intelligent intent interpretation, DAG task formulation, and explanatory synthesis above the authoritative Phase 1 deterministic engineering layer.

```text
User Request (NL)
    ↓
IntentPacket (Controlled Taxonomy)
    ↓
Context Resolution & Canonical Snapshotting (SHA-256 Digest)
    ↓
Task Plan DAG (Decomposed into Validated Read-Only Capabilities)
    ↓
Server-Authoritative Capability Execution Policy Check
    ↓
Deterministic Execution (Phase 1 Engineering & Verification Engines)
    ↓
Execution Breakdown (SUCCESS / PARTIAL / FAILED)
    ↓
AI Explanation (INFORMATIONAL ONLY)
    ↓
Execution Provenance & Integrity Digest Persistence
```

## 2. Non-Negotiable Invariants
1. **AI Engineering Authority = NONE**:
   AI copilot models cannot verify requirements, validate circuits, close reviews, or authorize designs.
2. **Autonomous Mutation = DISABLED**:
   The cognitive layer operates exclusively in read-only analysis and synthesis modes.
3. **Autonomous Approval = DISABLED**:
   No requirement, proposal, or review may be closed without human engineer authorization.
4. **Epistemological Boundary**:
   `UNKNOWN != PASS`, `UNKNOWN != SATISFIED`, `UNKNOWN != VERIFIED`.
   Calculated values are never confused with physically verified measurements.
5. **Zero Synthetic / Composite Scoring**:
   No arbitrary percentage readiness, overall plan scores, or composite quality metrics.
